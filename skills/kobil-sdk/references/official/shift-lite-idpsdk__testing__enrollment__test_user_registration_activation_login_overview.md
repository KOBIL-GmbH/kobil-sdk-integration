# Overview

The Security Server has to know the userId before you can use it for a user account activation and login. So we have always the following steps

* User registration - Creating a user account for a user
* User account activation - Adding a user account to an installed app on a device (e.g. smartphone)
* User account login - Doing a login with the registered user

### Prerequisites

You have to use an app version that is already registered at Security Server, see [**Add App in Security Server**](shift-lite-idpsdk__prerequisites__app-lifecycle__add-app__add_app_overview.md) and [**Register App Version**](shift-lite-idpsdk__prerequisites__app-lifecycle__register-app-version__register_app_version_overview.md).
