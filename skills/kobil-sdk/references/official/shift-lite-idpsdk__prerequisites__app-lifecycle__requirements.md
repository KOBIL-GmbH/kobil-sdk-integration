# Requirements from KOBIL App Security

Each KOBIL Secured app and all of its version numbers must be "registered" in Security Server as a protection mechanism against unauthorized connections from invalid apps.
In addition you must set app's Push Notification provider parameter to enable Push Notification for transaction confirmation ('TMS').
