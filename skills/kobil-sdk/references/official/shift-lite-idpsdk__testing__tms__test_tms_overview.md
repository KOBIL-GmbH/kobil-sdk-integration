# Overview

A user transaction confirmation ('TMS') is sent by the Security Server, triggered by customer backend (e.g. as part of a money transfer process). To test receiving and showing TMS in your app, you have to trigger TMS instead of a customer backend.

### Prerequisites

You have to use an app version that is already registered at Security Server, see [**Add App in Security Server**](shift-lite-idpsdk__prerequisites__app-lifecycle__add-app__add_app_overview.md) and [**Register App Version**](shift-lite-idpsdk__prerequisites__app-lifecycle__register-app-version__register_app_version_overview.md).  
You need an activated user account in your app on your device, see [**Test User Registration, Activation and Login in KOBIL Digitanium+ / KOBIL Shift Lite**](shift-lite-idpsdk__testing__enrollment__test_user_registration_activation_login_overview.md).
