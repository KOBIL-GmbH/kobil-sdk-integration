# User Management

The user management functionalities within an Identity Provider (IDP) system specifically focus on local user management, administrative tasks, and impersonation capabilities. Users are stored permanently in the IDP platform, and administrators can perform various actions.

### **User Management GUI**

* [Adding Users](https://developer.kobil.com/docs/idp-docs/administration/usermanagement/#add-user)
* [Updating User Information](https://developer.kobil.com/docs/idp-docs/administration/usermanagement/#update-user)
* [Enabling/Disabling Users](https://developer.kobil.com/docs/idp-docs/administration/usermanagement/#enabledisable-user)
* [Removing Users](https://developer.kobil.com/docs/idp-docs/administration/usermanagement/#remove-user)
* Impersonation:
  + [From Users List](https://developer.kobil.com/docs/idp-docs/administration/usermanagement/#impersonation)
  + [From User Details](https://developer.kobil.com/docs/idp-docs/administration/usermanagement/#impersonation)

### **Admin REST API**

* [User-related Functions](https://developer.kobil.com/docs/idp-docs/administration/usermanagement/#admin-rest-api)
  + Updating Users
  + Enabling/Disabling Users
  + Removing Users
* Interaction via Specific Endpoints
* Providing Relevant JSON Payloads

You can also utilize the Admin REST API for **user-related** functions, by interacting with specific endpoints and providing relevant JSON payloads.
